About me

I'm a full-stack developer with a passion for building things that work — clean backends, intuitive frontends, and systems that scale. I write Java and Spring Boot the way some people write essays: carefully, intentionally, with an eye for structure.

My approach to software is end-to-end. I've built secure authentication systems with OAuth2 and Spring Security, designed relational data models with JPA/Hibernate on MySQL, containerised apps with Docker, and wired up cloud services like Cloudinary and Spring Mail — all from scratch. On the frontend, I work comfortably with ReactJS, Angular, and Tailwind CSS.

When I'm not writing code, I dig into data — SQL queries, Python EDA, and turning raw datasets into insights that actually mean something. I care about clean code, good architecture, and shipping things that work.

Currently finishing my B.Tech at MNIT Jaipur and open to full-stack developer roles.
